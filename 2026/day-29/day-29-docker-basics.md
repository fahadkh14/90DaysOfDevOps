# Task 1: What is Docker?

## What is Docker?

Docker is an open-source platform that allows developers to build, package, ship, and run applications inside lightweight environments called **containers**.

It ensures that an application works the same way on every machine by packaging the application along with all its dependencies.

---

## What is a Container?

A container is a lightweight, isolated environment that contains:

- Application code
- Runtime
- Libraries
- Dependencies
- Configuration files

Containers share the host operating system kernel, making them much faster and lighter than Virtual Machines.

### Why do we need Containers?

Without containers:

- Applications may work on one machine but fail on another.
- Different software versions create dependency issues.
- Deployment becomes difficult.

Containers solve these problems by providing a consistent environment everywhere.

Benefits:

- Lightweight
- Fast startup
- Portable
- Easy deployment
- Resource efficient
- Consistent environments

---

# Containers vs Virtual Machines

| Containers | Virtual Machines |
|------------|------------------|
| Share host OS kernel | Have their own Guest OS |
| Lightweight | Heavy |
| Start in seconds | Start in minutes |
| Less resource usage | More CPU & RAM usage |
| Better performance | Slower than containers |
| Suitable for microservices | Suitable for complete OS virtualization |

# Docker Architecture

Docker mainly consists of four components:

### 1. Docker Client

The Docker Client is the command-line interface (CLI).

Example:

```bash
docker run nginx
```

The client sends commands to the Docker Daemon.

---

### 2. Docker Daemon

The Docker Daemon (`dockerd`) performs all Docker operations.

Responsibilities:

- Build images
- Pull images
- Run containers
- Manage networks
- Manage volumes

---

### 3. Docker Images

Docker Images are read-only templates used to create containers.

Examples:

- nginx
- ubuntu
- node
- mysql

---

### 4. Docker Containers

Containers are running instances of Docker Images.

One image can create multiple containers.

---

### 5. Docker Registry

A registry stores Docker Images.

# Task 3: Run Real Containers

## Run Nginx

```bash
docker run -d -p 8080:80 nginx
```

Explanation:

- `-d` → Detached mode
- `-p` → Port mapping
- `8080` → Host port
- `80` → Container port

Open browser:

```
http://localhost:8080
```

You should see the Nginx Welcome Page.

---

## Run Ubuntu Container

```bash
docker run -it ubuntu
```

Interactive terminal opens.

Try commands:

```bash
ls

pwd

whoami

cat /etc/os-release

exit
```

---

---

```bash

```


---

## Remove a Container


# Task 4: Explore Docker

## Detached Mode

```bash
docker run -d nginx
```

Detached mode runs the container in the background.

---

## Give Container a Custom Name

```bash
docker run -d --name my-nginx nginx
```

---

## Port Mapping

```bash
docker run -d -p 8080:80 nginx
```

Host Port → 8080

Container Port → 80

---

## Check Logs

```bash
docker logs my-nginx
```

Shows logs generated by the container.

---

## Execute Commands Inside a Running Container

```bash
docker exec -it my-nginx bash
```

If bash is unavailable:

```bash
docker exec -it my-nginx sh
```

Example:

```bash
ls

pwd

exit
```
