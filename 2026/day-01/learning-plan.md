# Learning Plan – 90 Days of DevOps

## Current Level

I am a 3rd-year student with basic knowledge of Linux and web development. I am currently learning DevOps and Cloud technologies to build practical skills and prepare for a career in the IT industry.

## My Understanding of DevOps & Cloud Engineering

DevOps is a set of practices that helps development and operations teams work together to build, test, deploy, and maintain applications efficiently. Cloud Engineering involves managing applications and infrastructure on cloud platforms such as AWS, Azure, and Google Cloud.

## Why I Am Learning DevOps & Cloud

* To build a strong foundation in modern IT technologies.
* To learn industry-standard tools and practices.
* To improve my practical skills through hands-on projects.
* To prepare for internships and future career opportunities.

## My Goals for the Next 90 Days

1. Strengthen my Linux, Git, and Shell Scripting fundamentals.
2. Learn Docker, Kubernetes, CI/CD, and Cloud basics through hands-on practice.
3. Build and deploy real-world projects and document my learning on GitHub.

## Core DevOps Skills I Want to Build

1. Linux Administration and Troubleshooting
2. Git and CI/CD Fundamentals
3. Docker and Kubernetes Basics

## Weekly Time Budget

* Monday to Friday: 2 hours per day
* Saturday and Sunday: 4–5 hours per day
* Total: Approximately 18–20 hours per week

## Consistency Plan

* Practice and learn every day.
* Maintain notes and update GitHub regularly.
* Complete daily challenge tasks before moving to the next topic.
* Revise key concepts every weekend.
* Track my progress and stay consistent throughout the 90-day journey.

## Where I Want to Reach

By the end of 90 days, I want to confidently use Linux, Git, Docker, Kubernetes, CI/CD, and basic Cloud services, build practical projects, and be ready to apply for internships and entry-level opportunities in DevOps and Cloud technologies.
